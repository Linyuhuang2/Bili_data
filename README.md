# Bilibili Conversation Dataset

**Status: Release in preparation**

This repository accompanies a study of tree-structured sarcasm detection and sarcasm-aware sentiment classification on Bilibili comments.

The dataset comprises **6,166 manually annotated comments from 254 conversation trees**. It includes binary sarcasm labels, three-class sentiment labels (negative, neutral, positive), and reply relations that preserve conversational structure.

## Data Availability

The dataset is **not yet publicly available**. Data curation, consistency checks, and anonymization are currently in progress. In particular, potentially identifying user information is being reviewed and removed or masked as appropriate before release.

We intend to make the prepared dataset, annotation guidelines, and experimental data splits available here once these steps and the relevant data-sharing checks are complete. **No release date has been set.**
